# Your Place 2.0: test build

A test build of the next version of [Your Place](https://github.com/yourplace3d/3d-city) (branch `v2`),
so it can be tried on a phone or tablet before it goes live. Not the live site, and not indexed by
search engines.

- Your Place · Data (steepness, traffic in Hamburg, your route): `data/`
- Your Place: the site's root

Built files only; the source is in `yourplace3d/3d-city` on branch `v2`. MIT licence, as there.

Terrain Tiles; traffic counts: Freie und Hansestadt Hamburg, Behörde für Verkehr und
Mobilitätswende (dl-de/by-2-0).
